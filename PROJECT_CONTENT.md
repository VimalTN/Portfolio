## 2. Chronoscape  ✅ content done

- **Year:** 2025 · MaAI Research Studio (Faculty: Gonzalo Garcia Perate, Lora Fahmy)
- **Team:** Vimal TN, Nithik Vairamuthu, Jinesh Narendra Jain, Seid Burka
- **Status:** Completed · Published on IAAC Blog
- **Hook:** An image-generation workflow that treats memory as design input for urban regeneration.
- **Description:** Tested on the 2025 Palisades Fire, Chronoscape structures residents' narratives and photographs into a memory layer that grounds AI reconstruction in the lived city — producing outputs that preserve real street geometry and neighbourhood identity where standard models hallucinate generic form.
